# 日常使用

应用的四个页面是“本地”“云端”“传输”和“设置”。

## 选择照片备份

在“本地”按相册、类型或备份状态筛选，长按或进入选择模式后勾选媒体。“全选”覆盖当前筛选范围，日期分组也可整组选择。确认选择后点击“备份”，在“传输”查看这一批任务。

对单项设置“不再自动备份”会保存自动排除规则；以后仍可手动选择上传。取消本次批次与长期排除是两个操作。

## 浏览照片和视频

本地和云端都可连续滚动，双指缩放在每行 1–8 项之间调整。点击照片打开全屏预览；视频初始暂停，点击播放后可拖动进度、调整 0.5×–2× 倍速。进入后台或退出播放器会暂停播放。

云端筛选支持相册、类型、设备、收藏及日期；切换条件后重新加载对应范围。已经缓存的同账户页面可离线浏览，并标为“离线缓存”。

## 保存原件到手机

在“云端”点击“选择”，勾选照片或视频，再点“下载”。未选择时点击下载会进入选择模式。下载先校验原件大小和内容哈希，再保存到系统照片库；按系统提示授予写入权限。

“传输”分别显示上传和下载进度。单项下载失败后仍可处理后续项目；退出或切换账户会停止当前下载。当前下载进度属于本次会话，重新打开后需要重新发起未完成下载。

## 查看和取消传输

队列区分准备、等待、上传、重试、失败和完成。暂时性网络问题会保留已准备分块，等待重试。完成状态由上传回执确认。

在批次菜单中选择“取消上传”可取消当前批次引用；同一媒体若仍被另一批次或自动规则引用，相关任务可能继续。处理失败任务前保留任务 ID 和错误提示，按[排查指南](troubleshooting.md)操作。

## 回收站与删除

云端“更多”提供回收站和重复项入口。移入回收站的媒体可恢复；永久删除位于回收站资产详情，并需要二次确认。永久删除会影响服务端副本，执行前确认已保存需要保留的原件。

手机本地删除和照片权限撤销不会自动删除云端媒体。应用清理也不删除系统照片原件。

## 退出与重新登录

“设置 → 退出”停止当前会话与后台任务，保留安全存储凭据和本地队列。再次显式登录时会核验仍有效的同实例凭据。授权码轮换或切换实例时，按[配置指南](configuration.md#账户)操作。
