# 备份设置

在应用“设置”页面管理账号、备份范围和缓存。开关与相册选择即时保存，登录前也可以调整备份偏好。

## 账户

服务器地址填写 HTTPS 根地址，例如 `https://backup.example.com`；“密码”填写实例授权码。地址不附加 `/admin`、`/v1`、查询参数或片段。首次登录步骤见[开始备份](getting-started.md)。

已有有效凭据时，应用验证并复用同一实例的设备凭据。管理员轮换授权码后，在账户行重新登录并输入新码；同实例继续使用原队列，其他实例使用独立队列。

## 备份选项

下表为新安装时的默认值；已有安装保留自己的设置。

| 设置 | 默认值 | 作用 |
|---|---|---|
| 自动备份 | 关闭 | 允许系统调度扫描和上传 |
| 仅 Wi-Fi 上传 | 开启 | 在允许的 Wi-Fi 网络条件下传输 |
| 后台仅充电时运行 | 关闭 | 开启后为后台任务增加充电条件 |
| 自动备份照片 | 开启 | 将照片纳入自动范围 |
| 自动备份视频 | 开启 | 将视频纳入自动范围 |
| 仅相机目录 | Android 开启 | 限制 Android 自动扫描范围；iOS 通过 PhotoKit 相册选择 |
| 自动备份相册 | 初始未手动选择 | 在可访问相册中选择实际备份范围 |
| 浏览磁盘缓存 | 256 MiB | 允许 64–1024 MiB，用于可重建预览图片 |

启用自动备份时，至少保留一种媒体类型，并检查界面中实际选择的相册。Android 的相机目录模式和 iOS 的相册模式按各自页面选择。手动备份使用本次选中的媒体，独立于自动相册扫描。

## 照片权限

“照片权限设置”打开系统应用设置。有限权限只覆盖用户允许的媒体；新授权或撤销后，返回应用会刷新本地图库。权限变化与本地照片删除只影响本地可见范围，不会自动删除云端副本。

## 后台执行

Android 使用 WorkManager，当前按 6 小时周期请求自动调度；实际时间受系统省电、后台限制、网络和电源条件影响。iOS 使用 BGProcessingTask 与后台 URLSession，由系统决定运行时机。需要立即确认结果时，前台打开应用并查看“传输”。

关闭“自动备份”用于停止后续自动调度；停止当前会话的上传和下载使用账户“退出”。单批次取消见[日常使用](usage.md)。

## 浏览缓存

“清空浏览缓存”删除可以重新下载的图库图片。上传队列、已准备分块和系统照片另行管理；清理影响见[数据维护](operations.md)。
