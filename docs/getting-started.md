# 完成第一次备份

准备一台[已安装 xszc 的设备](platform-setup.md)，并请 xszs 管理员提供一个备份实例的 HTTPS 根地址和实例授权码。首次可选两三张测试照片，保持应用在前台，方便观察结果。

## 1. 登录备份实例

1. 点击“本地”顶部的“备份”，或“设置”中的账户行。
2. 填写服务器根地址，例如 `https://backup.example.com`，地址以主机和可选端口结束。
3. 在“密码”输入框填写管理员提供的实例授权码，点击“登录”。
4. 等待账户行显示已登录或已配对。

实例授权码用于手机登录，管理员的 Web 登录密码用于管理后台。应用会把设备凭据保存在 Android 加密私有存储或 iOS Keychain 中。

## 2. 允许访问照片

按系统提示选择完整访问或部分访问，也可从“设置 → 照片权限设置”调整。图库只显示已授权的媒体：Android 13+ 分别授权照片和视频，Android 14+ 与 iOS 支持选择部分照片。

## 3. 手动备份少量媒体

在“本地”选择测试照片或视频，点击“备份”。切换到“传输”，观察准备、排队、上传和完成状态。首次验证时先保持自动备份关闭，便于确认本次选择的范围。

## 4. 确认备份结果

在“云端”打开刚上传的照片或视频，确认能正常查看。需要验证原件时，选择其中一项“下载”，在系统照片库检查保存结果。管理员也可在同一实例下核对设备与媒体记录。

## 5. 开启自动备份

在“设置”选择自动备份的媒体类型、相册和网络/电源条件，再启用“自动备份”。设置的默认值和平台差异见[配置指南](configuration.md)。后台由系统安排，定期打开“传输”查看实际完成情况。

连接或上传失败时，从[排查问题](troubleshooting.md)按当前现象处理。
