# 一次移动请求

本章跟踪客户端发出的请求。服务端路由和认证实现位于 [xszs](https://github.com/isarmg/xszs/tree/main/docs)。

1. 宿主读取当前连接快照，确认 HTTPS 根地址与账户/设备身份。
2. 使用设备 Bearer Token 发起同源请求；资源和视频请求保持同一来源。
3. 按 DTO 处理成功响应，或按 HTTP 状态、稳定错误码和重试字段处理失败。
4. 上传完成后保存回执；图库变化与同步游标在同一事务提交。

## 按失败类型处理

- 400/422：检查请求或业务数据，修正后再发起。
- 401/403：检查当前实例授权与设备凭据。
- 409：读取当前业务状态，判断身份或幂等冲突。
- 429：按 `Retry-After` 等待。
- 5xx/网络失败：保留队列并按有界退避重试。

服务端可能返回 `X-Request-ID` 和错误中的 `request_id`，可用于关联服务器日志；手机的本地扫描和队列日志仍按时间、任务及资源 ID 定位。

具体协议和身份见[参考](../reference/protocol-and-state.md)。
