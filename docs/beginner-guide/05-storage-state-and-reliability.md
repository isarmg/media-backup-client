# 本地状态与重试

移动数据库持久化任务、分块、批次、回执、绑定身份及图库游标。prepared 目录保存已准备的上传内容，系统照片库仍由用户和操作系统管理。

## 重开任务

已有准备结果的 `ready` 或到期 `retry_wait` 复用落盘分块。进程重开时，带准备结果的 `preparing`/`uploading` 回到 `ready`；尚未完成准备的任务回到 `discovered`，再次读取获准访问的源文件。

每次准备使用新的代次，持久化成功后回收同任务的旧代次。共享批次取消只移除当前引用，其余批次或自动引用仍可继续。完整备份角标依据全部原始资源回执计算。

## 图库同步

先取得快照水位，再读取完整元数据快照，随后应用增量事件。资产变化与 sequence 同事务提交；网络或授权错误不会推进游标。照片权限变化重建本地可见范围，不删除云端副本。

## 容量和清理

原件、分块与浏览缓存分别计量。单原件最多 2 GiB，准备前检查分块预算和剩余空间。浏览缓存可由界面清空；队列和分块保留未完成任务，维护规则见[数据维护](../operations.md)。更详细的状态与测试见[实现参考](../manual-backup-implementation.md)。
