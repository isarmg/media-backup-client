# Media Backup Client 0.3.0

独立 Client 仓库首次版本，包含 Android/iOS 和 Rust 移动核心，不包含 Server 安装包或服务端管理 Web。
发布附件包括 Android arm64 已签名 APK、iOS 未签名应用归档和 SHA256SUMS。iOS 归档不是可直接安装的已签名 IPA，需要使用自己的 Apple 签名环境重新构建、签名。

- 产品自身统一 Client 命名；Foundation Client 和 Server 所属协议固定完整 Git 提交。
- 新移动状态 epoch 为 `media-backup-mobile-v0.3-r1`，不读取旧队列或后台任务状态。
- Android 正式包必须使用受保护签名环境和固定证书，普通 CI 只构建 Debug；iOS 继续明确为未签名构建。
- Server 独立在 `isarmg/media-backup-server` 构建发行；产品不提供迁移或自动升级。
