# xszc 1.1.1

- 相册批次按编码后的字节数限制大小，避免大量或较长元数据导致单批请求超出预算。
- 保留图库交互状态，修正相机图片在预览和缩略图中的方向。
- iOS 到达备份窗口上限时保留待上传项目，后续可继续处理。
- iOS 取消视频进度拖动时重置拖动状态，恢复正常播放进度更新。
- 改进图库就绪、视频定位与 JNI 测试诊断，完善 Android 缩略图方向覆盖。
- 公共客户端支撑升级至 `xcsc 1.0.1`，固定 revision `d3e9b8db84e4ead70ec0bf8a596dbad697f7db24`；业务协议继续使用 `xszs-protocol 1.0.0`。

## 安装包

- Android：`xszc-android-1.1.1-arm64.apk`，最低 API 26，沿用既有正式签名身份。
- iOS：`xszc-ios-1.1.1-unsigned.ipa`，最低 iOS 26.0，实机安装前使用所有者的 Apple 身份签名。
- 两个平台的发行物附 `SHA256SUMS`。

Rust、Android 和 iOS 软件版本统一为 `1.1.1`；Android versionCode 与 iOS build number 均为 `1001001`。移动状态应用版本 `1.0.0`、SQLite revision 1、`xszc-mobile-v1` 和 ABI v1 不变，现有队列、上传回执、配对身份及自动排除规则继续沿用。

安装、签名与更新步骤见[平台部署指南](../platform-setup.md)。
