# Media Backup Client 0.3.2

- 修复 Android 将系统提供的应用目录别名直接传入严格原生路径校验的问题：仅解析 Android 应用根目录，继续拒绝内部目录及数据库文件的符号链接。
- 通过不跟随链接的文件描述符检查目录所有权，确保现有应用暂存目录为 0700；保留已有队列、账号和文件。
- SQLite 当前结构复核的临时快照改放在数据库所在私有目录，不再依赖系统默认临时目录；继续验证当前结构、权限和 WAL，不兼容或迁移旧格式。
- 备份失败信息增加阶段名称，区分目录准备、数据库打开、扫描、分块、上传及相册同步；不暴露 Rust 内部错误详情。
- 新增 Android 16 / API 36 模拟器真实 JNI 回归：入队、分块内容、完成、重新打开，以及目录别名、权限修正和链接拒绝。

发行号升级到 0.3.2；Rust crate、本地身份 0.3.0 / media-backup-mobile-v0.3-r1、ABI 和服务器协议不变。
从 0.3.1 覆盖安装无需清除数据或重新设置。0.2.1 的旧状态不读取、不迁移，需重新配置。

附件包括现有证书签署的 Android arm64 APK、iOS 未签名应用归档和 SHA256SUMS。
iOS 归档不是可直接安装的签名 IPA。本次不包含 Server 更新。

验证边界：Android 16 模拟器不能代替小米 13 / HyperOS 真机验收；
已复现并修复本地路径及临时目录导致的通用 native status 3 失败条件，但不宣称已证明手机上的唯一根因。
