# Media Backup Client 0.4.2

恢复明确的登录入口：本地、云端、传输、设置页面顶部均可打开账户登录，设置页也提供“登录 / 切换账户”。
登录使用服务器验证账户与密码，显示进行中、成功或失败结果；验证及账户绑定通过后才保存新凭据。
编辑登录表单不会提前切换正在使用的账户。未配置账户的云端页面提供直接登录入口。

Android 和 iOS 的照片选择控件移到缩略图右上角；点击图片预览，点击勾选控件选择，选中照片显示描边。
图库统一使用方形缩略图和简洁日期分组。备份按钮与选择数量固定在底部，清空选择随时可用。
云端高级筛选收进独立面板，设置按账户、备份偏好、缓存分组，传输批次增加进度与可展开详情。

增加 iOS 登录成功/失败回归测试及导航界面测试，CI 导出界面截图用于检查登录入口和页面布局。

iOS 继续要求 **iOS 27.0 及以上**，使用 Xcode 27 / iOS 27 SDK，build number 为 6。
IPA 为未签名包，安装前仍需重新签名。Release 提供 Android ARM64 签名 APK、iOS IPA 和 SHA256SUMS。
发行号为 0.4.2，移动状态身份、Rust 契约 0.4.0、SQLite revision 2 和 Foundation ABI v2 保持原样。
