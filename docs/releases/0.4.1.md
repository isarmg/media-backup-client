# Media Backup Client 0.4.1

iOS 最低系统版本提升至 **iOS 27.0**。Swift 应用、测试和 Rust 原生库的真机/模拟器切片使用相同部署目标。
CI 和正式 Release 使用 Xcode 27 / iOS 27 SDK，并在打包前检查工具链版本。
CI 明确选择 iOS 27 模拟器执行状态隔离测试。

IPA 打包增加 `MinimumOSVersion=27.0` 和 iOS 27 SDK 标记校验，拒绝旧系统目标、旧 SDK 或缺失标记的产物。
附件 `media-backup-ios-0.4.1-unsigned.ipa` 使用标准 `Payload/MediaBackup.app` 结构，
只能安装在 iOS 27 及以上设备；安装前仍需使用自己的 Apple 签名凭据或侧载工具重新签名。

本次发行号为 0.4.1，iOS build number 为 5。Rust 契约版本保持 0.4.0，
移动状态身份保持 `media-backup-mobile-v0.4-r1`、SQLite revision 2 和 Foundation ABI v2，
0.4.0 的当前账户、队列和缓存继续使用。Android 仅同步发行号与 versionCode。
Release 同时提供已签名 Android ARM64 APK 和 SHA256SUMS。

当前 Xcode 27 工具链处于预览阶段，见 [Apple 发行说明](https://developer.apple.com/documentation/xcode-release-notes/xcode-27-release-notes)
和 [GitHub Xcode 27 构建环境说明](https://github.blog/changelog/2026-07-16-xcode-27-runner-image-now-in-public-preview/)。
模拟器测试和 IPA 构建不替代真机相册、视频及后台调度验收。
