# Media Backup Client 0.3.1

- 修复 Android「检测连接」访问已移除的 `/health` 而返回 404；改为正式 `/healthz`，要求服务端返回 204。
- 支持服务器地址末尾的斜杠，避免健康检查生成重复斜杠。
- 新增真实 OkHttp 请求构造回归测试：路径、GET、无设备凭据、204 成功和非预期状态失败；正式签名前执行 Android 单元测试。
- 发行号由 `VERSION` 管理；Rust crate 和本地状态身份仍为 0.3.0 / media-backup-mobile-v0.3-r1，不改变数据库、凭据、队列或移动 ABI，不添加旧接口兼容。

填写 `https://backup.sarmg.org` 等 HTTPS 根地址，不添加 `/admin/`。连接检查不是登录校验；
设备注册仍使用「备份用户」账号，不使用平台管理员账号。

附件包括 Android arm64 正式签名 APK、iOS 未签名应用归档及 SHA256SUMS。
iOS 附件不是可直接安装的签名 IPA。Android 保持现有 application ID 和签名证书。
本次不包含 Server 更新，不改变服务器协议版本。

版本边界：上述状态格式不变是相对于独立客户端 0.3.0 源码而言。
若从已发布的 0.2.1 安装，本版本沿用仓库拆分后的新状态目录，不读取或迁移旧凭据、
本地队列和后台任务配置，需要重新填写连接信息并选择备份设置；不会删除服务器上的备份。
