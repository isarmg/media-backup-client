# Media Backup Client 0.4.4

修复 iOS 新建本地备份数据库时对应用沙盒外祖先目录的额外访问。路径验证和文件暂存改用 Foundation Client 0.7.1 的 Apple 原生防符号链接检查；不放宽备份文件权限、不删除旧队列。内置 SQLite 的路径规范化同样会访问沙盒外祖先；Apple 端使用产品专用 VFS 路径回调，先执行原生防符号链接检查，再交给原 SQLite Unix VFS 处理读写、锁和 WAL。

数据库打开失败现在显示固定阶段码 `MBDB-PATH`、`MBDB-CREATE`、`MBDB-VALIDATE`、`MBDB-CONNECT` 或 `MBDB-CONFIGURE`，不再统一隐藏成 `operation failed`。诊断不会包含账号、密码、数据库内容或完整路径。

新增真实 macOS 受限沙盒内的首次建库、账号绑定和关闭重开回归，保留 iOS 27 模拟器及 Android 16 全新/覆盖安装登录和图库测试。用户报告环境为 iPhone SE 2 / iOS 27 Beta 8；该真机上的最终登录需要安装此版本复验。

保留 0.4.3 的账号重建后旧队列隔离和图片选择缩略图修复。发行号 0.4.4；Rust/持久身份 0.4.0、SQLite revision 2、Foundation ABI v2 不变。Android 使用原发行签名，可直接覆盖安装；iOS 提供 unsigned IPA，需要使用自己的签名安装。
