# xszc 1.1.0

本次更新优化 Android 与 iOS 的本地图库和视频播放体验，正式标签为 `v1.1.0`。

## 本地图库

- 全部已授权照片和视频进入轻量目录，连续滚动浏览，取消每 150 项手动加载。
- 使用原生惰性网格，只创建屏幕附近的单元格；日期分组预先计算，刷新沿用稳定的资产 ID。
- 按实际显示尺寸请求缩略图并预取附近项目。Android 使用 32 MiB LRU 缓存及最多 3 个解码任务；iOS 使用 PhotoKit 系统缓存和预热机制。
- 备份状态和来源详情按需读取，浏览缓存上限为 768 项；全选覆盖当前筛选中的全部项目。
- Android 根据 MediaStore 版本和变更编号更新图库，iOS 应用 PhotoKit 增删改通知。授权范围变化时重新核对可访问项目；本地删除不触发云端删除。

## 视频播放

- 点击本地视频直接进入黑色全屏预览，初始暂停，点击播放按钮后开始。
- 移除旧预览页面的白色背景、文件名称、状态文字和自动备份排除文字。
- 本地和云端共用播放控件，提供可拖动进度条、缓冲进度、时间显示及 0.5×–2× 倍速。
- 播放时控件自动隐藏，点按画面再次显示；本地视频使用胶囊按钮选择备份，进入后台或退出时暂停。

## 安装和升级

Android 正式包为 `xszc-android-1.1.0-arm64.apk`，最低 API 26，使用既有正式签名，可覆盖安装 1.0.0。iOS 最低为 26.0，提供 `xszc-ios-1.1.0-unsigned.ipa`，安装前需要使用自己的 Apple 身份签名。两种产物均附 SHA256SUMS。

软件版本升级为 1.1.0，持久状态合同仍为应用版本 1.0.0、SQLite revision 1、`xszc-mobile-v1` 和 ABI v1。保留现有队列、备份回执、配对身份和自动排除规则；配套 Server API 仍为 `/v1`。

## 验证

回归覆盖 10,003 项元数据的全量索引、筛选和按 ID 读取详情，以及增量删除后保留自动排除规则。平台测试覆盖超过 150 项图库的连续滚动、刷新和全选，以及合成视频的默认暂停、播放推进、进度定位、倍速、备份选择和后台暂停。

正式资产由该标签的 Release 工作流构建，并验证 Android 唯一签名证书、应用 ID 和原生架构，以及 iOS IPA 版本和包结构。系统权限、实机视频格式兼容性和后台调度仍需要对应设备验收。
