# Media Backup Client 0.4.3

修复已复现的服务器重建后，同名备份账户登录在本地绑定阶段失败的问题。用户补充 Android 为覆盖安装、iOS 为全新安装；iOS 全新安装的故障尚待原生验证。本文件为未发布草稿。旧客户端只按服务器地址和用户名选择队列，新的账户 ID 因此撞上旧队列的身份保护，Android 显示 `Native status 3: operation failed`，iOS 显示 `ClientFailure error 0`。

- 登录时读取已有队列绑定；身份相同继续使用已有队列，账户重新创建时使用独立目录，保留旧队列、暂存文件和备份记录，不把旧任务自动发送给新账户。重复登录新账户继续使用其独立队列。
- 后台取得不同账户身份时要求重新登录，防止后台更新凭据后误用旧任务。
- iOS 原生错误实现 `LocalizedError`，不再将错误说明丢失为系统 `error 0`。
- 新增真实 Android JNI 与 iOS 原生回归：同账户重登、同名账户重新创建、新队列重登、旧队列与待办保留；C ABI 覆盖绑定查询与拒绝跨账户重绑。

发行号 0.4.3；Rust/移动持久身份 0.4.0、SQLite revision 2 和 Foundation ABI v2 保持不变。覆盖安装后重新登录即可，修复不要求清除应用数据。

附件：使用既有证书签署的 Android arm64 APK、iOS 未签名 IPA 与校验和。iOS IPA 需要按现有方式签名后安装。原生 CI 与人工真机验收是不同证据；发布后仍需两台出现问题的手机确认。
