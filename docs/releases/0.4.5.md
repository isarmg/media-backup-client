# Media Backup Client 0.4.5

修复 iOS 0.4.4 登录时报 `MBDB-PATH：无法访问备份目录`。Foundation URL 的 `resolvingSymlinksInPath` 可能移除 `/private` 前缀，将真实路径重新变为 `/var` 系统别名，随后被原生防符号链接检查拒绝。

现在仅对 FileManager 返回的系统 Application Support 目录打开句柄，通过 `F_GETPATH` 读取内核真实路径，并核对防符号链接打开结果及目录身份，再拼接账号目录。产品自己的目录和数据库符号链接仍被拒绝，不删除原数据，不修改 SQLite 格式。目录解析失败显示阶段和系统错误编号，不输出路径或凭据。

选择确认页不再依赖可选的系统预览：优先读取授权 PhotoKit 缩略图（允许加载 iCloud 媒体），失败时读取选择器授权的图片文件或视频封面，再尝试系统预览及 UIImage。图片从文件直接缩小到 320 像素；不把原件完整载入 UIImage。新增无系统预览、无 PhotoKit 的文件提供者回归，UI 测试必须验证缩略图已实际解码，不能仅检查占位格。保留 0.4.4 的 SQLite 沙盒修复及选择快照修复。新增真实 `/var` 别名的 macOS Swift 回归和 iOS 原生建库/重开/拒绝产品别名测试。模拟器与 CI 不能代替用户 iPhone SE 2 / iOS 27 Beta 8 最终验收。

本次发行仅包含 iOS 修复包及 SHA256SUMS。iOS 为 unsigned IPA，版本 0.4.5、build 9，需要自行签名安装。Android 继续使用 [0.4.4 已签名 APK](https://github.com/isarmg/media-backup-client/releases/tag/v0.4.4)，其平台代码不受本次问题影响。
