# Media Backup Client 0.4.7

Android and iOS now pair with the Server-managed instance authorization code and retain the resulting Client identity in protected platform storage. Authorization rotation reuses the instance queue while identity drift fails closed and requires explicit re-pairing.

The release rebuilds the Android APK and unsigned iOS IPA from the tagged source and verifies both mobile implementations against the same current protocol contract.

Client operations documentation now covers only the Android, iOS, Rust core and FFI delivery boundary. Obsolete Server deployment instructions were removed; pairing, secure local state, permissions, queues and native release checks are documented against the actual Client implementation.
